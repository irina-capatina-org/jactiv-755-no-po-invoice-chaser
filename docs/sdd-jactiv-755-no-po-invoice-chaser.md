## 1. API Workflow Overview

Weekday unattended control: query Coupa for invoices (status `draft`/`new`, last 7 days, credit notes excluded) lacking a linked PO, count them, send one Slack Block Kit DM to the AP SME. Silent on a clean day (BR-07). No Coupa record modified (BR-09).

| Trigger | Orchestrator weekday schedule, 10:00 Europe/Bucharest (org architectural considerations §1; OQ-07 resolved) |
| Delivery | Automation Cloud, EU, modern folders (org architectural considerations §1) |

## 4. Execution Flow

Single Try/Catch wraps the sequence. Any unhandled exception marks the job failed; no retry (BR-08). PO linkage fields (live-tenant verified 2026-09-21, org architectural considerations §4): `invoice-lines[].po-number` and `invoice-lines[].order-header-num`. Non-empty on any line = linked. Description-only PO = not linked (BR-02). [ARCHITECT REVIEW: OQ-05 — SME should confirm these are the authoritative fields.]

## 6. Error Handling

No retry (BR-08). Single outer catch marks job failed; no notification sent on failure.

| ID | Failure | Detection | Response |
|---|---|---|---|
| S1 | Coupa query failure | HTTP non-200 or exception on step 4 | Job failed; logged |
| S2 | Slack delivery failure | `ok !== true` or HTTP error on step 10–11 | Job failed; logged |
| S3 | Endpoint unreachable | Timeout/connection error | Job failed; logged |
| S4 | Credential error | Integration Service bind error | Job failed; logged |
| S5 | Unhandled exception | Any uncaught runtime exception | Job failed; stack trace logged |

Business exceptions B1–B3 are filter predicates inside `Javascript_FilterAndCount`, not error branches.

## 8. Testing Strategy

### Happy Path

| Scenario | Condition | Assertion |
|---|---|---|
| Invoices found | ≥1 invoice, no linked PO, not credit note | `qualifying_count > 0`; `slack_sent = true`; DM received at WLX9BD8FN; count in header and body; coupaUrl button present |
| Clean day | All returned invoices have linked PO | `qualifying_count = 0`; `slack_sent = false`; no DM sent; job succeeds |

### Business Exceptions

| Scenario | Condition | Assertion |
|---|---|---|
| Credit note (B1) | `invoice-type === 'Credit Note'` | Excluded from count; in `exclusionLog` (BR-03) |
| Description-only PO (B2) | PO text in description; `po-number`/`order-header-num` empty on all lines | Counted as qualifying (BR-02) |
| Clean day (B3) | `qualifyingCount = 0` | No Slack message; job succeeds (BR-07) |

### System Errors

| Scenario | Condition | Assertion |
|---|---|---|
| Coupa failure (S1) | HTTP 4xx/5xx | Job failed; no Slack sent; error in Orchestrator log |
| Slack failure (S2) | `ok: false` | Job failed; Orchestrator log |
| Endpoint timeout (S3) | Unreachable | Job failed; Orchestrator log |
